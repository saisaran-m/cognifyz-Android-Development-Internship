# Level 2: Intermediate

This folder contains the tasks completed for **Level 2 (Intermediate)** of the Cognifyz Android Development Internship.

## Tasks Included

### Task 3: List Display
* **Objective:** Develop an app that displays a scrollable list of items using an adapter.
* **Steps Completed:**
  1. Created `ListDisplayActivity` hosting a `ListView` element.
  2. Implemented a custom `ArrayAdapter` with alternating row colors.
  3. Bound static technical programming language data and wired item click listeners with toast feedback.
* **Files:**
  * `Task 3 - List Display/ListDisplayActivity.java`
  * `Task 3 - List Display/activity_list_display.xml`
  * `Task 3 - List Display/list_item.xml`

### Task 4: Basic UI Layout
* **Objective:** Build an app with multiple activities, XML layouts, and intent communication.
* **Steps Completed:**
  1. Designed the main layout with input fields and navigation triggers.
  2. Implemented `ProfileActivity` to receive intent extras and display user profile details.
  3. Implemented `SettingsActivity` with switch toggles for app preferences.
* **Files:**
  * `Task 4 - Basic UI Layout/BasicUILayoutActivity.java`
  * `Task 4 - Basic UI Layout/ProfileActivity.java`
  * `Task 4 - Basic UI Layout/SettingsActivity.java`
  * `Task 4 - Basic UI Layout/activity_basic_ui_layout.xml`
  * `Task 4 - Basic UI Layout/activity_profile.xml`
  * `Task 4 - Basic UI Layout/activity_settings.xml`
