# Level 2: Intermediate

This directory contains the completed source code and layout files for Level 2 (Intermediate) of the Cognifyz Android Development Internship.

## Tasks Included

### Task 3: List Display
* **Objective:** Develop an application that presents structured information in a scrollable list view.
* **Implementation Details:**
  1. Created `ListDisplayActivity` hosting a `ListView` component.
  2. Implemented a custom `ArrayAdapter` featuring alternating row background colors for improved visual hierarchy.
  3. Bound static programming language datasets and wired item click listeners to deliver Toast alerts.
* **Files:**
  * `Task 3 - List Display/ListDisplayActivity.java`
  * `Task 3 - List Display/activity_list_display.xml`
  * `Task 3 - List Display/list_item.xml`

### Task 4: Basic UI Layout
* **Objective:** Construct a multi-activity application demonstrating structured layout design and intent parameter routing.
* **Implementation Details:**
  1. Designed the primary dashboard with input fields and navigation triggers.
  2. Implemented `ProfileActivity` to receive Intent extras and render structured user credentials.
  3. Implemented `SettingsActivity` featuring toggle switches for application configuration settings.
* **Files:**
  * `Task 4 - Basic UI Layout/BasicUILayoutActivity.java`
  * `Task 4 - Basic UI Layout/ProfileActivity.java`
  * `Task 4 - Basic UI Layout/SettingsActivity.java`
  * `Task 4 - Basic UI Layout/activity_basic_ui_layout.xml`
  * `Task 4 - Basic UI Layout/activity_profile.xml`
  * `Task 4 - Basic UI Layout/activity_settings.xml`
